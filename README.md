# О проекте

Проект представляет собой сервис, который обеспечивает необходимые возможности в рамках выбора подходящего для переговоров помещения офиса.  

# Используемые технологии

- Python
- FastAPI
- Pydantic

# Запуск

Запуск сервера командой:
```
python -m uvicorn app.main:app
```

Просмотр реализованного API по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
